# pythonnet-stub-generator

Creates Python Type Hints for Python.NET libraries

This is a fork of https://github.com/MHDante/pythonnet-stub-generator with various changes to make it work better with https://github.com/Shadowth117/PSO2-Aqua-Library. 

# Usage

```
PythonNetStubGenerator.Tool.exe --out="../py_project/typings" "dll_folder/MyLib1.dll" "other_folder/MyLib2.dll"
```
